QUESTIONS & ANSWERS

Everything You Need to Know

Direct answers regarding Miyori installation, playback quality, and Android compatibility.

How do I install Miyori on my Android phone? +
Download the MIYORI.apk file from this site. Once downloaded, tap the file in your browser or Downloads folder. If Android displays a prompt saying "Install unknown apps", tap Settings and enable Allow from this source. Follow the on-screen prompt to complete installation.
What Android version is required? +
Miyori requires Android 7.0 (API 24 Nougat) or higher. It is compiled and optimized for modern Android 14 and 15 (API 34/35/36) with support for predictive back gestures and dynamic edge-to-edge rendering.
Does Miyori save music files to my device storage? +
Yes! When you cache or download a track offline in the native app, Miyori saves the audio file directly into your device's Music/Miyori folder. You retain complete ownership of your library.
Can I connect to my personal Navidrome / Subsonic server? +
Yes. Miyori features native Subsonic API integration. In the app settings, enter your server URL, username, and password/salt to browse and stream your personal server music collection alongside local files.
Why does the APK package ID show com.example.auralis? +
Auralis was the development codename for the native Kotlin music engine. The bundled MIYORI.apk release binary contains the verified ExoPlayer engine and native Jetpack Compose UI.
