COMMON INQUIRIES

Frequently Asked Questions

Everything you need to know about installing, streaming, and managing your audio library.

Download MIYORI.apk directly from this website. When prompted by Android, grant your browser permission to install apps from this source ("Install Unknown Apps"). Once granted, open the APK file and tap Install. MIYORI is compatible with all devices running Android 7.0 (API Level 24) or higher.
Downloaded audio files are stored in your device's standard public music directory at Music/Miyori. They are saved in standard MP3/AAC containers with embedded ID3 metadata, meaning you retain full ownership and can play them in any third-party media player.
MIYORI streams and downloads in high-fidelity 320 kbps (or data-saving 160 kbps). This is high-bitrate lossy audio (AAC/MP3) optimized for transparent sound reproduction without incurring unnecessary mobile bandwidth consumption.
The player automatically matches track metadata against LRCLIB, an open community-maintained synchronized lyrics database. If embedded LRC tags exist inside the local file, MIYORI prioritizes the local file tags for immediate zero-latency display.
Yes. MIYORI provides first-class Subsonic API support. Enter your server URL, username, and token in the app settings to stream, search, and download your entire self-hosted library directly to your device.
The official release is version 1.2.0 (versionCode 3), packaged as a 10.62 MB standalone APK. It runs on Android 7.0+ (API level 24 and above) and is engineered with 100% Kotlin, Jetpack Compose, Media3 ExoPlayer, and Android AudioEffect integration.
