FREQUENTLY ASKED QUESTIONS

Questions, answered.

What is Miyori?

Miyori is a luxury Android music player crafted around high-bitrate streaming, synchronized lyrics, local music ownership, offline downloads, and self-hosted server integration. Built in 100% native Kotlin and Jetpack Compose under 11 MB.

Which Android versions are supported?

Miyori supports Android 7.0 (Nougat, API 24) and all subsequent versions up to Android 15 (API 35). It is engineered to run smoothly on both budget devices and high-refresh-rate flagship screens.

Can I listen to music offline?

Yes. When you download a track, the full audio file is stored in your device's filesystem at Music/Miyori with complete metadata and album artwork. You can play it offline inside Miyori or in any other music player.

How do synchronized lyrics work?

Miyori fetches word-for-word synchronized lyrics from LRCLIB where available, as well as reading embedded USLT/ID3 tags directly from your audio files. You can tap any line to seek playback instantly.

Can I import my Spotify playlists?

Yes. Simply paste a public Spotify playlist link into Miyori. The app parses the track metadata and resolves each track against high-bitrate streaming sources without needing a paid Spotify account.

Does Miyori support local music & self-hosted servers?

Yes. Miyori indexes local files on your internal storage and SD card while filtering out audio junk like ringtones and WhatsApp voice notes. Additionally, it features native Subsonic / Navidrome integration for streaming personal self-hosted libraries.

Can I customize audio with an equalizer?

Miyori provides multi-band equalization, bass boost, and virtualizer sound shaping using native Android AudioEffect sessions, ensuring audio processing runs with minimum latency on hardware that supports it.
